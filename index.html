关键发现举例：排版层级表写的是 2.5rem，但 Hero 实际用的是 2.2rem——规范自相矛盾。配色表有 12 个色值但没说什么时候用哪个。布局参数完全缺失——导航多高？Hero 多高？ Example finding: the typography scale said 2.5rem but the Hero used 2.2rem — a contradiction. The color palette had 12 values but no usage rules. Layout parameters were completely missing.
