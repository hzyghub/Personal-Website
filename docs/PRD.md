## 1. 项目概述

### 1.1 定位
综合在线名片——任何人看了都能快速了解黄朝阳是谁、能做什么、做过什么。

### 1.2 核心目标
- 求职敲门砖：面向HR/招聘方，争取AI产品经理岗位面试机会
- 个人品牌：面向行业同行，建立"懂数据、能落地、有方法论"的专业形象
- 项目作品集：证明实际动手能力（全栈开发 + 数据竞赛 + 方法论设计）
- 社交名片：方便快速分享个人介绍

### 1.3 目标用户
| 用户 | 需求 | 关注板块 |
|------|------|----------|
| HR/招聘方 | 快速评估候选人匹配度 | Hero + 技能 + 履历 + 项目 |
| 技术面试官 | 验证技术深度和实战能力 | 项目详情 + AI协作理念 |
| 行业同行 | 了解专业背景和方法论 | AI协作理念 + 项目 + 性格画像 |
| 潜在合作伙伴 | 评估合作可能性 | 项目 + 联系方式 |

## 2. 设计决策

### 2.1 视觉风格：温和质感卡片流
- **概念**：浅色温暖基调，卡片流布局，通过卡片大小表达信息优先级
- **配色**：暖白(#fafaf8) + 青绿(#2a9d8f) + 珊瑚(#e76f51)
- **布局**：卡片流、全宽大卡与并排小卡交替
- **动态**：滚动淡入动画、hover 微上浮+阴影加深
- **字体**：系统字体栈，标题 font-weight:600，正文轻盈

### 2.2 语言
- 中英双语，支持一键切换
- 默认中文，右上角语言切换器

### 2.3 技术方案
- 纯静态站（HTML + CSS + JS）
- 部署到 GitHub Pages
- 零依赖、零构建工具
- 响应式设计，适配移动端

### 3.5 AI协作理念 — Spec Engineering

**布局**：左文右图（概念关系图）

**内容**：
- 板块标题：AI协作理念 | My AI Collaboration Philosophy
- 核心概念说明：
  - **意图-执行差距**：AI只理解你明确表达的意图，而非你真正的意图。这个差距是AI协作的根本问题。
  - **规格工程**：系统化地编写AI能正确理解和执行的规范文档。不是写文档，是训练你的AI搭档。
  - **人机分工模型**：永久性人类工作（领域知识、真实意图发现、差距识别、责任归属）vs AI工作（格式化、审计、执行）
  - **活标准双环审查**：用案例检验标准，用"卡壳点"反哺标准改进。A类卡壳修标准，B类卡壳修案例。
- 引用：「好的规范不是写给人类看的说明书，而是让AI能独立行动的作战手册。」

**视觉**：
- 右侧用CSS绘制概念关系图（意图→规范→执行，双环审查反馈箭头）
- 概念卡片带编号和accent色

## 5. 技术规格

### 5.1 文件结构
```
/
├── index.html          # 主页面（中文默认）
├── en/
│   └── index.html      # 英文版（或同页面JS切换）
├── css/
│   ├── style.css       # 主样式
│   ├── animations.css  # 动画效果
│   └── responsive.css  # 响应式
├── js/
│   ├── main.js         # 主逻辑（语言切换、导航、滚动动画）
│   ├── radar.js        # 技能雷达图绘制
│   └── particles.js    # 背景粒子效果（轻量CSS/JS）
├── assets/
│   ├── images/         # 头像、项目截图等
│   └── fonts/          # 如需自定义字体
└── docs/
    └── PRD.md          # 本文档
```

### 5.2 性能目标
- 首屏加载 < 2s（3G网络）
- 无外部依赖（不加载CDN库）
- 总大小 < 500KB（不含图片）
- Lighthouse 评分 > 90

### 5.3 浏览器兼容
- Chrome/Edge 最新2个版本
- Firefox 最新2个版本
- Safari 最新2个版本
- 移动端 Safari / Chrome
