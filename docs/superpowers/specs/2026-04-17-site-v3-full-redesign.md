# 个人网站 v3.0 全面重设计规范

> 版本：v3.0 | 日期：2026-04-17 | 状态：已批准 | 审查：活标准双环审查 v3.0-post-review

## 1. 设计决策记录

### 1.1 为什么要重做

v2.0 是从暗色科技主题到暖色卡片流的视觉改造，但本质是"换个壳"。v3.0 是从需求、叙事、视觉、到代码的全面重构。原因：

- **定位升级**：从求职简历站升级为个人数字资产——面向行业人脉和设计社区
- **叙事重构**：从"能力清单"转变为"人机协同思想者"的身份表达
- **内容策略转变**：从"全部堆在主站"到"主站是目录，详情在子页"
- **设计追求**：从"好看"到"设计大奖水准"

### 1.2 核心决策

| 决策项 | 结论 | 理由 |
|--------|------|------|
| 目标受众 | 行业人脉 + 设计社区 | 投资人、创业者、合作伙伴 + 设计师和创意总监 |
| 情感目标 | 打破预期→产生好奇→感受深度→付诸行动 | 四层递进的访客旅程 |
| 叙事锚点 | IntentBridge——人机协同思想的创造者 | 最具差异化，其他能力围绕它展开 |
| 视觉方向 | 融合混搭：杂志排版 + 电影节奏 + 侘寂克制 | 不模仿任何单一风格，形成自己的语言 |
| 内容语气 | 直接对话型（"你好。所有人都在研究怎么让AI更强大。"） | 最能引发连接感和行动冲动 |
| 技术栈 | 纯 HTML/CSS/JS，零依赖 | 用户不懂代码，零依赖最适合长期可维护性 |
| 架构 | 多页：主站 + 方法论页 + 项目页 | 扩展性最佳，更新互不影响 |
| 站点定位 | 长期数字资产，持续迭代 | 与人生、事业、AI时代共同成长 |

### 1.3 明确排除

以下功能不在 v3.0 范围内：

- **暗色模式**：v3.0 只有亮色主题。暗色模式需要独立的配色系统，不适合当前阶段。
- **博客/文章系统**：网站是展示型，不是内容型。思考输出通过设计过程板块体现。
- **项目详情弹窗**：使用独立页面，不使用弹窗。
- **简历 PDF 在线预览**：HR 导向的简历是独立资产，不在个人站内。
- **Google Analytics**：v3.0 不做数据分析。
- **自定义域名**：使用 GitHub Pages 默认域名。

### 1.4 关键定位修正

**IntentBridge 不是"规格工程"。** 它不是 Prompt Engineering / Context Engineering / Spec Engineering 层面的东西。它是人机协同的思想/哲学——核心命题是"人的意图如何完整可靠地转化为AI的执行"。比工具和框架层面更高，是方法论和思想层面。

## 2. 站点架构

### 2.1 布局参数

| 参数 | 值 | 说明 |
|------|-----|------|

### 2.2 文件结构

```
hzy-site/
├── index.html                    # 主站——入口大厅
├── intentbridge.html             # 方法论页——活文档旗舰页
├── projects/
│   ├── afc.html                 # AFC 数据智能平台
│   ├── tianchi-prediction.html  # 二手车价格预测
│   └── fund-flow.html           # 蚂蚁金服资金预测
├── css/
│   ├── style.css                # 全局设计系统（变量、排版、组件）
│   ├── layout.css               # 布局系统（grid、spacing）
│   └── animations.css           # 所有动画
├── js/
│   └── main.js                  # 交互逻辑（导航、滚动、语言切换）
└── assets/
    └── images/                  # 头像、项目图片
```

### 2.3 CSS 文件职责

| 文件 | 内容 | import 顺序 |
|------|------|-------------|
| style.css | CSS 自定义属性（变量）、排版规则、组件样式（标签、按钮、卡片、元数据栏）、配色 | 1（被其他文件 import） |
| layout.css | 布局系统：容器、grid、flex、间距工具类、响应式 @media 断点 | 2 |
| animations.css | 所有动画：@keyframes、滚动入场类、hover 过渡、Hero 入场序列、prefers-reduced-motion | 3 |

主 HTML 文件只引入 style.css，style.css 内 @import layout.css 和 animations.css。

### 2.4 页面关系

- **index.html** — 只给"钩子"，传达核心印象，链接到完整页
- **intentbridge.html** — 方法论的活文档旗舰页，有版本号和 changelog
- **projects/*.html** — 每个项目独立页面，各有叙事节奏，更新互不影响

### 2.5 扩展指南

| 操作 | 改动范围 |
|------|---------|
| 新增项目 | 新建 `projects/xxx.html` + 主站加一张卡片 |
| 更新项目 | 只改对应 `projects/xxx.html` |
| 方法论迭代 | 只改 `intentbridge.html` + 更新版本号 |
| 新增人生阶段 | 主站时间线加一条 |
| 全站版本升级 | 更新导航栏和页脚的版本号 |

### 3.4 标志性设计元素

**§ 章节标记系统：**
- 每个主要区块用 `§0 §1 §2` 标注
- 格式：小号大写 + 主色 + letter-spacing 0.2em
- 是导航锚点，不是装饰

**版本徽章：**
- 网站标题旁：`v3.0`（青绿底白字）
- 方法论页：`v0.3`（随方法论迭代更新）
- Footer 始终显示版本号

**标签样式：**
- 默认：浅背景 + 深色文字 + 小圆角
- 核心标记（★）：强调色边框高亮
- 状态标签：`已审查 ✓` / `持续迭代中` / `NEW`

**分隔线：**
- 极细线条：1px，暖灰色 #e8e4de
- 不是卡片边框，是"段落间距"的视觉化
- 40px 宽的居中短线作为装饰性分隔

**元数据栏：**
- 页面顶部：状态、更新日期、审查轮数、性质
- 页面底部：版权 + 版本号 + 更新日期

## 5. 交互与动画

### 5.1 动画哲学

每一个动效都必须回答："它让访客更好地理解了什么？" 引导视线、暗示层级、传达质感、创造惊喜时刻。不做粒子效果、3D旋转、弹跳、闪烁。

### 5.2 动画清单

**① 滚动入场**
- 实现：CSS transition + JS IntersectionObserver
- 效果：从下方 20px 淡入，opacity 0→1
- 时长：600ms，缓动 cubic-bezier(0.25, 0.1, 0.25, 1)
- 交错：同级元素 100ms
- 只触发一次

**② § 章节标记竖线**
- 实现：纯CSS
- 效果：区块进入视口时，§ 标记左侧竖线从上往下画出
- 时长：400ms，延迟 200ms（在区块淡入之后）
- 颜色：§0 主色、§1-§2 灰色、★ 珊瑚色

**③ 链接下划线生长**
- 实现：CSS ::after 伪元素
- 效果：hover 时下划线从左到右生长，width 0%→100%
- 时长：300ms ease
- 颜色：#2a9d8f

**④ 项目卡片悬停**
- 实现：CSS transition
- 效果：左边框出现（transparent → 主色 2px），文字颜色加深，"查看→"右移 4px
- 时长：250ms ease-out
- 不使用上移+阴影加深的常见模式

**⑤ 页面过渡**
- 实现：View Transitions API（浏览器原生，MPA 模式）
- 技术路径：在 `<head>` 中添加 `<meta name="view-transition" content="same-origin">`，配合 CSS `@view-transition { navigation: auto; }`。无需 JS 即可实现多页间淡入淡出。
- 效果：当前页淡出 opacity 1→0（300ms），新页淡入
- 降级：不支持时直接跳转，无动画

**⑥ Hero 入场序列**
- 实现：CSS @keyframes
- 编排：
  - 0ms：头像淡入（opacity 0→1 + scale 0.9→1，从中心微放大）
  - 300ms：名字淡入（opacity 0→1，无位移）
  - 700ms：核心问题句淡入（opacity 0→1 + translateY 10px→0，从下方微升）
  - 1100ms：分隔线 + 副标题（opacity 0→1）
  - 1500ms：CTA 按钮淡入（opacity 0→1）
- 总时长 1.8s

### 5.3 技术约束

- 所有动效均纯 CSS 实现
- JS 仅用于 IntersectionObserver 触发 + View Transitions
- 零动画库
- prefers-reduced-motion 媒体查询：动画减弱或关闭
