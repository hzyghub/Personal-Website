# 设计文档：视觉风格全面重设计 — 卡片流 + 温和质感

> 日期: 2026-04-16 | 状态: 已批准 | 范围: v1.0 全面视觉重做

## 1. 背景

当前网站使用暗色科技风（深蓝底 + 电光蓝 + 粒子效果），风格偏"AI生成感"，缺乏个人特色。用户要求转向**现代浅色系、有设计感**的方向。

## 2. 设计决策

### 2.1 视觉风格：温和质感卡片流

- **概念**：所有内容打碎为独立卡片，通过卡片大小表达信息优先级，瀑布流式排列
- **参考调性**：Gumroad 的亲和力 + Notion 的卡片逻辑 + Linear 的排版克制

### 2.2 配色系统

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#fafaf8` | 暖白，带微黄调 |
| 区分隔背景 | `#f0efeb` | 暖灰，用于卡片间区域 |
| 卡片背景 | `#ffffff` | 纯白 |
| 主色（青绿） | `#2a9d8f` | teal，柔和但不寡淡 |
| 主色浅 | `#e8f5f3` | 青绿浅色，用于标签背景、区域点缀 |
| 辅助色（珊瑚） | `#e76f51` | 暖珊瑚，少量点缀/CTA |
| 正文色 | `#2d3436` | 深灰，不是纯黑 |
| 次要文字 | `#636e72` | 中灰 |
| 卡片阴影 | `0 2px 12px rgba(0,0,0,0.06)` | 极淡 |
| 卡片圆角 | `16px` | 大圆角 |

### 2.3 字体处理

- 继续使用系统字体栈（零外部依赖约束不变）
- 标题 `font-weight: 600`（从 800 降低，更轻盈）
- 正文 `line-height: 1.7`（保持）
- 增加 `letter-spacing` 在标签和小字上

### 2.4 动效

- **保留**：滚动淡入（reveal）、hover 微上浮
- **新增**：卡片 hover 时阴影加深（`0 4px 20px rgba(0,0,0,0.1)`）
- **删除**：粒子 canvas、发光效果、旋转几何体、雷达图绘制动画

## 3. 页面结构

从 7 个传统板块转为卡片流，按优先级排列：

### 卡片 1：Hero 大卡（全屏宽度）

- **布局**：居中排列，头像在上，文字在下，大留白
- **背景**：白底 `#ffffff`，与全站一致
- **内容**：
  - 头像：圆形裁剪，无边框发光，自然融入
  - 名字：黄朝阳 / Chaoyang Huang（深灰 `#2d3436`，大号加粗）
  - 副标题：AI 产品经理（青绿色 `#2a9d8f`）
  - 一句话定位：用数据理解世界，用AI重构产品，用规范桥接人机意图
  - 标签：数据产品 | AI协作 | 规格工程 | 全栈开发 | INTP（青绿色胶囊，浅底 `#e8f5f3` + 深字）
  - CTA：查看项目（青绿色实心按钮）/ 联系方式（描边按钮）
- **特点**：干净通透，用排版而非色彩创造视觉冲击

## 4. 响应式断点

| 断点 | 行为 |
|------|------|
| > 1200px | 多列卡片布局，Hero 全屏 |
| 768px - 1200px | 并排卡片缩小间距，Hero 适当缩放 |
| < 768px | 所有卡片全宽单列，导航汉堡菜单 |

## 5. 技术改动范围

| 文件 | 改动程度 | 说明 |
|------|----------|------|
| `css/style.css` | 重写 | 颜色变量、卡片系统、布局、动画全部重做 |

## 6. 性能影响

- **正面**：删除粒子 canvas 和雷达图后，JS 体积和运行时开销降低
- **目标**：首屏加载 < 2s 不变，总大小应该更小（少了 canvas 绘制代码）
- CSS 体量可能略增（卡片样式），但总体可控
